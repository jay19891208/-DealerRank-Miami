# DealerRank Miami

**Find a licensed car dealer in Miami.**

> **Showcase repository.** The source code is private. This page describes the product.

![DealerRank Miami](screenshots/website.jpg)

## What it is
A public dealer directory and ranking platform for **Miami-Dade and Broward**.

- 478 public dealer profiles across 46 local areas
- License details shown on each profile, pending records clearly marked
- Buyers share their vehicle, budget and area with up to three Verified dealers
- Verified dealers compete for the top positions in a transparent ranking
- Secure payments: only completed payments count in the ranking

## Built with
`JavaScript` · `Supabase / PostgreSQL` · `Vercel`
